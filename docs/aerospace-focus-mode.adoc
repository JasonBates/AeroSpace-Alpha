= aerospace-focus-mode(1)
include::util/man-attributes.adoc[]
:manname: aerospace-focus-mode
// tag::purpose[]
:manpurpose: Toggle a centred focused window over a dimmed desktop
// end::purpose[]

== Synopsis
[verse]
// tag::synopsis[]
aerospace focus-mode [-h|--help] [--stay-on-monitor]
// end::synopsis[]

== Description

// tag::body[]
{manpurpose}

Focus Mode temporarily centres the focused window using the configured
`single-window-width-rules`. Other windows keep their tiled positions beneath a
dark, click-through backdrop. Press the binding again to restore the normal
view. With three or more displays, the focused window moves to the middle
display; with two, it moves to the macOS main display. With one display, it
stays there. The window returns to its original tiled position when Focus Mode
ends. The window tree and tile sizes are not changed.

Pass `--stay-on-monitor` to keep the window on its workspace's monitor instead.
For example, use `ctrl-alt-cmd-z = 'focus-mode --stay-on-monitor'` on a laptop
while keeping the default binding on a desktop. This choice lasts until Focus
Mode ends, including when selecting another window in the same workspace.

Use `resize height +100` or `resize height -100` to adjust the Focus Mode
window's height while keeping it vertically centred. Width stays unchanged.
The height is limited to the available display height, with a minimum of 200
points (or the available height on smaller displays). The adjustment belongs
to that window for its lifetime and does not affect its normal tiled layout.
For example, bind `ctrl-alt-cmd-shift-equal` and `ctrl-alt-cmd-shift-minus` to
these commands; keep the existing unshifted bindings for width.

Keyboard focus commands can select another window in the same workspace while
Focus Mode stays active. Clicking outside the focused window, switching
workspaces, losing the focused window, or disabling AeroSpace exits the mode.

Add a binding such as `ctrl-alt-cmd-z = 'focus-mode'` to your configuration.

// end::body[]
