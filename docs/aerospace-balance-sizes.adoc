== Synopsis
[verse]

aerospace balance-sizes [-h|--help] [--workspace <workspace>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}. Tiled splits are equalized recursively. Per-window adjustments
for lone-window width and Focus Mode width and height, and minimum sizes learned
from apps that refused a smaller frame, are cleared on the target workspace. An active mouse-resize gesture on that workspace is cancelled so it
cannot reapply stale sizes. Ordinary floating window frames are unchanged.
