# AeroSpace Alpha v1.0

Alpha v1.0 has the same code as [v0.8](0.8.md). Only the version number changes.

SwipeAeroSpace chooses its socket protocol from the AeroSpace version number and
treats anything from 0.1 to 0.20 as an old AeroSpace. Alpha's 0.x numbers
therefore made it use a protocol this build does not speak, so three-finger
swipes did nothing while SwipeAeroSpace kept running. It logged
`Detected AeroSpace protocol version: 0`, then `Heartbeat failed` every five
seconds.

From v1.0 SwipeAeroSpace picks the right protocol with no change on its side.
Alpha version numbers should stay at 1.0 or above from here on.
