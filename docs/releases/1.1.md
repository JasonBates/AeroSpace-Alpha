# AeroSpace Alpha v1.1

v1.1 adds one command option to [v1.0](1.0.md). The upstream base is unchanged.

## `resize --independent`

`resize --independent width +100` (and `-100`) changes the width of one
top-level column and leaves its neighbours at their widths. Under adaptive
layout the centred arrangement as a whole grows or shrinks by the same amount
and stays centred, so widening one window no longer narrows the one beside it.

The width lasts until the number of columns changes or `balance-sizes` runs.
Once the arrangement has grown to the full usable width of the display there is
no free space left, and the command takes space from the neighbours as it does
without the flag. Shrinking always leaves the neighbours alone.

```toml
alt-shift-minus = 'resize --independent width -100'
alt-shift-equal = 'resize --independent width +100'
```

Stock AeroSpace and earlier Alpha builds reject the flag, so remove these
bindings before going back to one of them. Details are in the
[build notes](../personal-build.md#adaptive-widescreen-layouts).
